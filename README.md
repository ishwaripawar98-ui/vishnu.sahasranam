# Śrī Viṣṇu Sahasranāma — Modern Interactive Website

Pre-synced with the Challakere Brothers recitation, complete English & Marathi (मराठी) meanings for all 171 verses (1,000 sacred names), and the full Origin Story (*Anuśāsana Parva* & Sahadeva's sacred mālā).

## Run Locally
```bash
python3 server.py
```
Then open `http://localhost:8080` in your browser.
